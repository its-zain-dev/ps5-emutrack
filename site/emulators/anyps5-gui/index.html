Release Notes

Highlights

  • Library is now the home screen. Add your folders once, then launch, convert or queue every game from one list.
  • Conversion queue as a side panel. Open it from the top bar on any tab, with live progress and a badge showing how many games are waiting.
  • Real progress bars for source builds and for the WinLibs / FFmpeg downloads.
  • Smoother, tidier interface: a floating top bar, a Back to top button and animations that respect reduced motion.
  • Windows fix: the relinker build no longer fails when the app folder has spaces in its path.

Library

  • Clearer app structure. Library is the first tab and the default view. Convert is the manual / batch tool. The old Play tab is renamed By path, for launching a converted folder that is not in the Library. Short on-screen hints and a mini flow strip (1 · Game → 2 · Mode → 3 · Convert) explain each page, and the cards are numbered and renamed (1. Select the PS5 game, Converted game folder, Launch).
  • The main hub. Add dump and output folders once, then launch, convert or queue from the list. Empty states offer direct actions (add folders, convert a game, open Queue).
  • Cleaner toolbar. One compact bar: Folders, refresh and view-toggle icons, the All · n | Done · n | Pending · n sliding segment, and Queue all (only when there is something to convert). Search sits next to the title.
  • Sticky Actions column. In table view the Actions column stays fixed on the right while the other columns scroll horizontally, with a solid background so scrolled cells do not show through.
  • Smarter queue buttons. Once the queue has games, a dump without a package shows Add to queue as its main action, which becomes Remove from queue when it is already in. With an empty queue, Convert starts right away (no extra confirmation when it is the only game) and grid cards get a compact queue icon next to it. Removing is blocked with a hint while the queue is running.
  • Animated buttons. When a game's actions change (for example Convert → Launch after a conversion), the buttons cross-fade, and the status text fades in when it changes.
  • Game details window. More relaxed spacing, and the Delete buttons are red and kept apart from the main actions.

Conversion queue

  • A side panel instead of a card. A Queue button in the top bar (with a count badge) opens a right-hand drawer, similar to browser download managers. It works from every tab; Esc or a click outside closes it. Adding games from the Library, Queue all or the Convert page opens it automatically.
  • Live progress. A progress bar in the footer shows "Working on <game> · N%" and updates in real time while the queue runs. When the queue starts, the panel closes by itself and the log slides into view.
  • Clearer footer. Add games (Current game · Folder… · Archives…) and the run controls (Convert queue / Stop) are grouped together; Clear sits next to the list title.
  • Polish. Slide-in/out animation, staggered row entrance, and respect for prefers-reduced-motion. Each item shows the game icon (grayscale while pending, full colour when done). The Remove button is no longer clipped on the right.

Builds and downloads

  • Real progress bar for source builds. When the build prints [N/TOTAL] lines (CMake/Ninja), the progress bar follows them instead of looping. This also applies to the libs target, which was the only build step that did not use it. A live "Building: X% (N/TOT steps)" line shows elapsed and remaining time.
  • Real progress for downloads. The MinGW-w64 (WinLibs, ~270 MB) and FFmpeg downloads fill the progress bar and update a single line in place ("Download: 17 / 255 MiB") instead of adding a new log line every few seconds. A "Download complete" message is shown at the end.
  • Progress while unpacking the toolchain. Unpacking WinLibs shows "Unpacking: N / TOT files" and fills the bar.
  • The bar goes back to indeterminate between steps and when a step fails or is retried.

Interface

  • Floating top bar. When you scroll down, the top bar (version, Queue, Report, Settings) condenses into a floating pill with shorter labels, so the Queue button and its badge are always within reach. The version number now lives in this bar.
  • Back to top. A round button appears at the bottom right after scrolling down and takes you back to the top with a short animation.
  • Log feedback. Launching a game, creating a shortcut or starting a conversion scrolls to the log with a brief slide-in highlight, instead of a plain jump.
  • Livelier buttons. Option chips zoom softly on hover and have a press effect (respecting the bubble-animation setting and prefers-reduced-motion).
  • Smoother collapsible sections. The open/close animation also animates padding and margins, can be interrupted by clicking again, and no longer jumps at the end.
  • The header tagline now reads "Your games in one place · Convert when needed · Launch from the Library".
