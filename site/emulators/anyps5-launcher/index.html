Release Notes

What's new

Library: delete games

  • Open the game card menu (three dots) and choose Delete
  • Removes the game folder from your library roots
  • If Windows blocks the delete, the launcher can elevate with UAC and retry

Convert status in the library

  • Converted games show progress and result in the library (in progress, OK, or failed / unfinished)
  • Broken or unfinished converts are easier to spot before you hit Play
  • The Converted output folder is created only when Convert actually starts (no empty stub folders)

Convert reliability

  • Clear Console ERROR blocks (What failed / Why / What to do) stay in place
  • Convert still hard-fails on real problems (relinker errors, real encrypted SELF modules, missing MinGW DLLs in the output)

Upgrade

Use Update Now from v1.2.4+, or download AnyPS5-Launcher-windows.zip.

Bugfixes

  • Fixed a false Convert failure when unwrap left backup files (for example *.selfbak) next to already decrypted modules
  • SELF skips are fatal only when there is no unwrapped sibling module
  • Converted modules: 0 fails only when real module files are present
  • MinGW check fails only when DLLs are missing from the game libs folder (not when the PC source path is gone but libs already has them)
  • Failed converts no longer get marked playable; successful converts no longer stay stuck as in progress after a metadata warning
  • Console "Likely cause" prefers real tool FAIL lines instead of echoing the launcher ERROR box
