Release Notes

New

  • Frame generation with MihawkGen, thanks to mihawk-99: [display] framegen = 2 (or 3, 4) shows 2x (3x, 4x) the frames a Vulkan game presents. DXVK, Zink and Vulkan games all work (#722).
  • Direct3D 12 through vkd3d-proton 3.0.1: wine: {dxvk: true, vkd3d: true} in an install script. Feature level 11_1 on the console (#711).
  • In-game menu on L3+R3 ([display] menu), with a keyboard input entry. A two-finger touchpad click opens the PS5's on-screen keyboard and types the line into the game (#707, #726).
  • Single-program titles: one Windows program as its own app on the home screen, without the launcher (#719).
  • A second DualSense as a second keyboard player (#427).

Controls

  • Hold Options + Create for 3 seconds to close a game (#720).
  • The touchpad's left half is Back and its right half is Guide; mouse wheel works (#721, #715).
  • L2/R2 vibrate with the rumble, and the controller stays connected while the PS menu is open (#712, #725).

Memory and fixes

  • Games see the console's real memory (12 GiB), instead of almost none, which some games refused to start with (#688).
  • Wine's own heap moved out of the game's flexible memory, leaving 5–26 MB more of it for the game (#470, thanks to leolobato).
  • Thread and fiber stacks use what Windows uses: 3000 fibers take 49 MB instead of 3.1 GB. 64-bit games can reserve up to 512 GiB of address space (#727, with leolobato's patch).
  • .NET and SMAPI games with large mod folders no longer run out of file handles (#697).
  • Emulators like DuckStation that write-protect 4 KB pages work (#718), plus fixes to audio resampling, OpenGL games and closing (#699, #701, #698).
  • Root certificates updated to Mozilla's 2026-10-20 store.

Installing

  1. Download prospero-win-<version>.zip below and unzip it. You get a folder

called PPSA99995.

  1. Upload that folder to /data/homebrew/ on your PS5 and let your loader

register it.

  1. Follow Getting started

to add your first game.

SHA256SUMS lets you check the download: sha256sum -c SHA256SUMS.

Updating from an earlier version: replace the whole PPSA99995 folder. Your
games, profiles and prefixes live in /data/prospero-win and are kept.
