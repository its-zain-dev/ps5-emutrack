Release Notes

﻿!Demon's Souls with DLSS Frame Generation
Demon's Souls with DLSS Frame Generation 2x: 53 FPS shown, 27 FPS from the game (RTX 5080, Ryzen 7 7800X3D).

First release of the SuperMedo version of KytyPS5 for Windows x64.

Download: KytyPS5-SuperMedo-windows-x64.zip. Unpack it anywhere, start KytyLauncher.exe, choose Add game... and pick your game folder (the one with eboot.bin and sce_sys).

What's inside: the emulator (built for any x86-64 CPU with AVX2, optimized with PGO), the Kyty Launcher (self-contained, no .NET install needed), the shader tools (kyty_shader_precompile.exe, kyty_seeds.exe, precompile-windows.ps1: no Python needed), the Visual C++ runtime DLLs, the license, third-party notices and the guide (README.md).

Demon's Souls shaders: the first Play reads the game's list of shaders from your game files and prepares them for your graphics card (about two minutes, once). For no first-time stutters at all, run Shaders → Precompile all shaders once (about an hour).

Highlights (details in SUPERMEDO.md):

  • Kyty Launcher: game library, per-game settings, Demon's Souls effect presets, shader status, FPS measurement.
  • DLSS Frame Generation starts on recent NVIDIA drivers (Demon's Souls; needs NVIDIA's Streamline SDK, not included: see the guide).
  • Sound stays in sync in long sessions; a game pad dropping out no longer closes the game.
  • God of War Sons of Sparta runs (red-zone protection off, set by the launcher).

Requirements: Windows 10/11 64-bit, AVX2 CPU, 32 GB RAM, a recent GPU driver (NVIDIA RTX with 12 GB or more recommended).

No games, game files, system software or NVIDIA files are included. Not affiliated with Sony Interactive Entertainment. GPL-2.0; source in this repository.
