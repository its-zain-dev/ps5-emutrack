Release Notes

Lumen Emu 0.1.0 build 5 for iOS and iPadOS

This preview targets ARM64 iPhones and iPads running iOS or iPadOS 17.4 or later. The IPA is intended for sideloading and local signing with AltStore Classic. Both the PS4 and PS5 cores require JIT. Installing this build and enabling JIT through AltStore Classic still need to be verified on a physical iPhone.

Installation and JIT setup

  1. Install the IPA with AltStore Classic
  2. Enable JIT on iPhone

Core changes

  • The PS4 core uses FFmpeg for AAC decoding and Mbed TLS 3.6.7 for HTTPS. Apple Security verifies certificate trust and hostnames.
  • The PS5 core uses the project's SPIR-V transformations for its native Metal renderer on iOS.
  • The on-device JIT component is built from StikJIT 2.0.1 and idevice 0.1.68 using RustCrypto and a pinned Cargo.lock. The separate JIT extension uses AGPLv3. Dependency provenance and license notices are in the source archive and in Legal/stikjit inside the IPA.

Testing and compatibility

  • The matching build installed and launched on the iPhone 18 Pro simulator. All four automated tests passed, including the PS4 and PS5 JIT probes. The Succi demo reached the title screen and displayed “Press X to start.”
  • Super Meat Boy (PS4), Brotato (PS4), and Dreaming Sarah (PS5) were playable in earlier tests on an iPhone 15 Pro.
  • Other titles still need testing, and 3D game compatibility needs further fixes.

The LumenEmu-iOS-0.1.0-build5-source-material.tar.gz archive contains the corresponding source, pinned dependency revisions, and instructions for rebuilding and relinking the static libraries.
