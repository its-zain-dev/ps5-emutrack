Release Notes

The signed APK includes the full dashboard and both emulator runtimes. Lumen Emu 0.1.8 (Android build 12) reads extracted PS4 and PS5 games directly from the folder you select. It requires Android 13 or later and an ARM64 device.

Download the signed Android APK · Banners driver source and build scripts

  • PS4 startup handles more Vulkan surfaces and reports unsupported drivers in the library. An empty library filter now opens safely.
  • Choose 720p or 1080p and toggle game audio for the next launch. Supported Adreno 6xx and 7xx devices can select Turnip Banners Standard.
  • PS4 memory, texture filtering, stencil rendering and embedded shaders have been improved. The Android dashboard lists ABZÛ and The Pathless as Playable on Xiaomi 12.
  • The PS4 runtime uses Mbed TLS. The PS5 runtime validates Vulkan shaders with standalone Khronos tools.

The signed APK was installed in place on Xiaomi 12 running Android 15. The direct folder picker preserved the existing folder and all nine games. Succi rendered frames and returned to the dashboard through its game menu.
