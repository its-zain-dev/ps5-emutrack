Release Notes

AnyPS5 Desktop 0.1.28: a Graphics page for PS1 games in the launcher's own window, with better defaults from the start (by B-Howell), Full Screen as the games' default (by Lenny4250gh), Polish (by QguAr71), downloads that try again by themselves and stay on screen when they stop (reported by QguAr71), and on Windows no more launcher freezes while a game's window is busy. The engine is unchanged: it pairs with AnyPS5-ARM 0.2.41, whose Windows and Linux engine (6667cd4b7) the launcher already offers.

This is still an early preview. Please report what works and what doesn't in the issues.

What's new

  • PS1 games in the launcher's window look better from the start, and have a Graphics page. The game's menu (PS button) has a new Graphics row after Audio. Its page holds Internal resolution, which moves there from the menu's first page and now also offers 6x and 8x for the strongest graphics cards, Smooth textures (Off, Smooth or Extra smooth), Fix wobbly 3D and Widescreen. Each lists only what the emulator offers. A choice is kept for later PS1 games, except Widescreen, which is kept only for the game you turned it on in. A PS1 game now starts with wobbly 3D fixed and the console's dithering removed; the dithering cannot be turned back on. Smooth textures and Widescreen stay off unless you turn them on. Smooth textures also softens sprites and can leave seams in 2D art, and Widescreen can make 2D games and drawn backgrounds look wrong. Settings that do not work in the launcher or only trade accuracy are hidden, and a value an earlier version saved for one is no longer used. That includes the per-game fixes switch on the Advanced page, which is on again for everyone, so the emulator's own fixes for individual games always apply. PS2 games get the same page (Internal resolution up to 8x, Sharper textures, on from the start, and Widescreen) once an emulator host with a PS2 emulator (LRPS2) is released. Host 1.1.0 has none, so PS2 discs still start in PCSX2. Thanks to B-Howell, who built this.
  • Games now start in Full Screen by default. A game with its own Display choice keeps it. A Default display that was still the old Window at 75% moves to Full Screen, and a Window at another size stays a window. Settings › Default display puts every game back in a window. Thanks to Lenny4250gh, who built this.
  • On Windows, the launcher no longer freezes while a game's window is busy. When a game opened its window and then went on loading, the launcher could stop answering for as long as the game loaded, or until it was closed if the game hung, because it waited on that window to size it, bring it to the front or take a screenshot. Now it only asks, and leaves a window that does not answer alone: F11 still reaches it, and a screenshot of a covered game that is not answering fails with the usual message. It has not been tried on a Windows machine yet. Reported by Harris851.
  • Downloads try again by themselves, and a stopped engine download stays on screen. A download of the engine, the PS1 emulator, ffmpeg or a launcher update that loses its connection, stalls for 30 seconds or is refused by GitHub's file host now tries again up to four times, carrying on from where it stopped. If it still fails, Settings › AnyPS5 engine says "Download of … stopped at N%" with the reason, and selecting the row carries on from there. The first-start card says the same, and choosing it carries on too. A file GitHub does not have, or one whose checksum is wrong, is not asked for again. The new texts are in every language. Thanks to QguAr71, who reported it.
  • The launcher is in Polish. Choose Polski in Settings › Behaviour › Language. A game whose language follows the launcher's then starts in Polish. Thanks to QguAr71, who translated all of it. The new Graphics page is in Polish too.
  • Custom relinker options know the engine's two new options. --function-symbol-roots can be added and is passed as typed. --to-avx is chosen by the launcher, as --to-intel is, so typing it says it is left to the launcher.
  • The language files no longer list seven texts twice (reporting a message and its reasons). What the launcher shows does not change, and the translation check now catches a text listed twice.
  • PS2 games do not play in the launcher's window yet. The signed emulator host (anyps5-retro-host 1.1.0) carries only SwanStation, the PS1 emulator. The Graphics page, save states and the Internal resolution row come to PS2 games once a host with LRPS2, a PS2 emulator, is released. Until then PS2 discs start in PCSX2 as before.
  • Engine. Unchanged since 0.1.27: AnyPS5-ARM 0.2.41's Windows and Linux engine (6667cd4b7, Settings → AnyPS5 Engine).
  • Built by CI. All five files of this release come from the repository's CI, from the release commit. Before they were signed, each one was checked to hold no launcher test build.

Thanks

Thanks to the testers on Discord, whose reports keep shaping AnyPS5. B-Howell built the PS1 Graphics page and its defaults. Lenny4250gh made Full Screen the games' default. QguAr71 translated the whole launcher into Polish and reported the stalled engine download that led to downloads trying again by themselves. Harris851 reported the Windows freeze at a game's start.

Install

Windows 10/11 (x64): run AnyPS5-Desktop-Setup-0.1.28-x64.exe (per user, no admin needed. It installs over earlier versions). SmartScreen may say "Windows protected your PC": click More info → Run anyway. Portable: unzip AnyPS5-Desktop-windows-x64.zip and run anyps5_desktop.exe (SDL2.dll and the Visual C++ runtime are beside it). Already on 0.1.3 or later: the launcher offers this update by itself. With Scoop: scoop bucket add anytogether https://github.com/AnyTogether/scoop-bucket, then scoop install anytogether/anyps5-desktop.
