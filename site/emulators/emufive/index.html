Release Notes

EmuFive 1.0.12: no more black screen with emufive.mode=

What's new

  • Fixed: a black screen with emufive.mode= in bootargs.txt (PS4 Multiboot #10). EmuFive set the TV's 1080p mode, then its home screen switched to another 1920x1080 mode (59.96 Hz, 173 MHz) that isn't one of the TV's modes, and some TVs show nothing with it. The home screen now keeps the mode EmuFive set. Checked on a PS4 Pro at 1080p and at 4K.

Update

Settings, System, Software update. No restart needed: the home screen starts again by itself.

If your screen is black because of emufive.mode=, remove it from bootargs.txt first, update, then add it back.

From 1.0.3 or earlier, start the update once by hand (see the README's Changelog).

New installs

Use the ps5-ps4-rootfs.tar.xz of this release.
