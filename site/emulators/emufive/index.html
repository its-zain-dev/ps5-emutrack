Release Notes

EmuFive 1.0.8: big games run much faster

What's new

  • Games with very large buffers run much faster. 1.0.7 uploaded every recently used buffer whole each frame, which for a game like Teardown meant over 3 GB per frame. Now only small buffers (up to 4 MB) are uploaded that way; large ones are tracked by page again. Teardown on a PS4 Pro went from under 1 FPS to about 2.4 FPS. DREDGE keeps its 1.0.7 speed and clean sound.
  • A new emulator build (KytyPS5 589bd14 with EmuFive patches 0001–0032).

Teardown and other big games: more GPU memory

Teardown also needs the GPU to be allowed up to 5 GB of system RAM, or it stops with GPU out of memory. Use the bootargs.txt of PS4 Multiboot v1.5.0-beta-5 (copy it to /data/linux/boot/ over FTP), or add amdgpu.gttsize=5120 ttm.pages_limit=1310720 to the end of the line in your own.

Update

Settings, System, Software update. No restart is needed. Coming from 1.0.6 or earlier, it installs 1.0.7 first, which also updates the PS4 Mesa (see the 1.0.7 notes).

From 1.0.3 or earlier, start the update once by hand (see the README's Changelog).

New install

Copy ps5-ps4-rootfs.tar.xz from this release to /user/home/ and install it from the PS4 Multiboot menu. It has 1.0.8 and the new PS4 Mesa built in.
