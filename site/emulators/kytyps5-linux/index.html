Release Notes

chenxiao07's KytyPS5 v20261007 (commit 9348901) for Demon's Souls (PPSA01341 1.07 / 1.05), packaged for Linux / SteamOS.

The emulator is chenxiao07's Windows build, unchanged (kyty_emulator.exe and everything else from KytyPS5-v20261007.zip). It runs under Wine or Proton with three scripts added (see LINUX.md):

  • demons-souls.sh: starts the game under Proton's Wine (or Proton's launcher with PROTON=1), with the fixes Wine needs: WINEDEBUG not -all (otherwise exit 253), GPU_BUFFER_PAGES and BUFFER_RECLAIM off (otherwise a GPU page fault under RADV when a save loads). It also waits for Steam Input's virtual gamepad and shows the FPS counter (KYTY_FPS_HUD).
  • precompile-linux.sh: the static shader precompile for the Linux graphics driver (about 20 min). The precompiled cache from Windows can't be used under Wine: it belongs to the Windows driver.
  • build-appimage.sh: optional AppImage of the launcher.

Quick start (SteamOS)

  1. Install Proton Experimental in Steam.
  2. Unpack: tar -xzf KytyPS5-v20261007-linux.tar.gz
  3. Put your own dump of the game in ~/Games/Demon's Souls/PPSA01341-app0 (or pass its path).
  4. ./precompile-linux.sh once (and after each Mesa / SteamOS update).
  5. ./demons-souls.sh, or add it to Steam as a non-Steam game without a compatibility tool. Use FULLSCREEN=1 %command% in the launch options for full screen.

Tested on SteamOS with a Ryzen 5 9600X and a Radeon RX 9070 XT (Mesa RADV 26.1, Proton Experimental 11.0): about 34–36 fps while walking at 2560x1440.

No game files, keys or firmware are included. Use only a game you have dumped yourself.
