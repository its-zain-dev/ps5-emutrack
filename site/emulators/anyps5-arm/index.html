Release Notes

AnyPS5-ARM 0.2.41 brings PS1 games into the Mac launcher's own window, through the signed PS1 emulator host that Settings › Emulators can now download (anyps5-retro-host 1.1.0 with SwanStation, by B-Howell), with save states, an Internal resolution choice and the PS menu that AnyPS5 Desktop has (B-Howell's Desktop work, ported to the Mac). A game now starts from its cover (designed by Lenny4250gh for AnyPS5 Desktop), and quitting the launcher while a game plays closes the game first and gives it time to save. AnyPS5 Desktop 0.1.27 brings save states and Internal resolution to PS1 games on Windows and Linux. The engine has not changed since 0.2.40, and the phone app stays AnyPS5 Remote 1.23. Like every release, it is signed.

Mac launcher

  • Settings › Emulators can download the PS1 emulator. With emulator games turned on, a new row downloads the AnyPS5 emulator host with SwanStation from its signed releases (now anyps5-retro-host 1.1.0). Nothing is downloaded until you select it. The download's signature and every file are checked before it is installed, and again before every game. Select the row later to look for an update.
  • PS1 games can play in the launcher's own window. Once the PS1 emulator is downloaded, a new switch shows beside it, Run PS1 games in the separate host, and the first download turns it on. Then a PS1 disc from the emulator library plays inside the launcher through the emulator host and SwanStation, and DuckStation is not needed. The picture keeps the game's shape, and the game pauses while the launcher's window is not in front. Two controllers play ports 1 and 2, the keyboard plays port 1, and each controller vibrates for its own port. A PS1 BIOS goes in the folder a new row in Settings › Emulators opens, and a game that cannot start says why. Screenshots, clips and Remote Play's phone pad do not cover these games yet. With the switch off, PS1 discs start in DuckStation as before.
  • The PS menu for these games. The PS button opens the game's menu: Resume, the discs of a multi-disc game, Save state and Load state, Audio (volume and mute), Internal resolution, Controller, Console and Advanced, then Close game.
  • Save states. Save state and Load state have eight slots per game, each with the date and time it was saved and a small picture of that moment. Saving over a slot asks first, and a state made by another version of the emulator or from another game is refused with a plain message. Loading a PS1 state also puts its memory card back to that moment. Each game keeps its states in its own folder next to its memory cards. They are for playing alone, and nothing online uses them. They need emulator host 1.1.0.
  • Internal resolution. The menu's new row after Audio draws a PS1 game sharper: Native, 2x, 3x or 4x. It lists only the values the emulator can show, the choice is kept for later PS1 games, and the game changes in a moment. If the emulator cannot show a value you saved, the game uses the largest one it can and the row says so. Higher values need a faster graphics card.
  • PS2 games stay in PCSX2 for now. The launcher can also play PS2 discs in its window through an emulator host that ships LRPS2, a PS2 emulator, but no released host has it yet: host 1.1.0 carries only SwanStation. Until one does, Settings › Emulators shows no PS2 rows, the PS2 Internal resolution row stays hidden, and PS2 discs start in PCSX2 as before. The emulator library now also lists CSO and ZSO images in a folder named PS2, and a game's retro.json can name a PS2 CSO, ZSO or ELF file.
  • A game starts from its cover (designed by Lenny4250gh, who wrote it for AnyPS5 Desktop; this is the Mac port). While a game loads, the launcher shows its artwork with its icon, its name and the moving line. In full screen the cover fades out over the game once its window has settled. In a window it fades out on the home screen, with nothing over the game. It never stays while you play. Turn it off in Settings › Default Display › Start animation, or per game in Game Settings › Display › Start animation. With reduced motion the fade is very short. Esc or ○ still cancels a start before the game's window shows.
  • Quitting closes the game first. Cmd-Q, the window's close, Quit AnyPS5 and an update's Restart Now now ask a game that is still playing to close, as Close Game does, and give it eight seconds to save. Quitting during an engine build from Git stops the build's tools, and quitting during a call never waits more than three seconds for it. This is the Mac counterpart of Lenny4250gh's fix for Windows.

These changes were built and tested by GitHub CI. They have not been tried on a real Mac yet: please report what you see.

Windows and Linux: AnyPS5 Desktop 0.1.27

  • Save states and Internal resolution for PS1 games in the launcher's window, both by B-Howell, with emulator host 1.1.0, and better DualShock 3 advice in Settings › Controllers. The PS2 resolution row stays hidden until a host with LRPS2 is released. The full list is in AnyPS5 Desktop 0.1.27.
  • Engine: AnyPS5-toolkit-windows-6667cd4b7.zip and AnyPS5-toolkit-linux-6667cd4b7.tar.gz / .zip, built by CI from this release's tag (Ubuntu 22.04, glibc 2.35, for Linux).

Engine

No change since 0.2.40. The engine files carry this release's version.

The Mac engine is built for macOS 14 as before.

Built by CI

Every engine and app file of this release comes from GitHub CI at the v0.2.41-arm tag: the Mac app and engine on a GitHub Mac, the Windows and Linux engine on Windows and Ubuntu 22.04. The release Mac only signs them. The phone app is AnyPS5 Remote 1.23 from 0.2.35, unchanged.
