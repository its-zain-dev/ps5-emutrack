Release Notes

int22 is int21 plus a faster Astro Bot and Astro's Playroom, shader lists in the package, one preset file per game, the latest upstream KytyPS5 changes and work on other games; the older notes are in docs/release-notes-history.md. The first launch rebuilds the shader and program caches once, so the first minutes can stutter. This build needs a CPU with AVX2, BMI2 and FMA (Intel Core 4th generation, AMD Ryzen, or newer); on an older CPU it says so and exits.

  • Faster (Astro Bot, Astro's Playroom): less work on the thread that hands the game's draws to Vulkan, shader code tuned for NVIDIA GPUs, a new profile-guided optimisation profile trained on both games, and host code for x86-64-v3 CPUs. On one PC (Ryzen 9 7950X3D, RTX 3090, 120 Hz; int21 and int22 booted in turn, one boot each, the desktop in use), Astro Bot without game patches: Sky Garden 50.5 -> 55.2 fps (+9%), pirate island 51.9 -> 53.3 fps (+3%), sponge 40.8 -> 53.0 fps (+30%). Astro's Playroom: CPU Plaza 71.8 -> 76.7 fps (+7%), GPU Jungle unchanged (71.9 -> 71.0 fps). Where the GPU is the limit the gain is smaller.
  • Astro Bot, sponge level: the level's fluid simulation made the game's threads wait for the GPU at every write to memory the GPU had just written; those pages are now copied back ahead of time (KYTY_READBACK_EAGER_WRITES=1, on in the Astro Bot preset).
  • Shader lists in the package: PipelineLists holds a shader list for Astro Bot (1,203 shaders, 5,922 pipelines) and Astro's Playroom (324 shaders, 732 pipelines). Press Precompile in the game list before the first start and the listed shaders are built then, not while you play. Thanks to the players on Discord who sent their lists. Lists for six other games, recorded with this build, are included as well.
  • Export list: the new button below Precompile makes a shader list from your own play sessions (ShaderListExports/<title>-<version>-shaderlist.kyplst). It holds the list the game came with here plus what your sessions added, also for games that keep their shaders in data files. It holds no shader code and no game data; send that one file if you want your list in the next release.
  • One preset per game: next to u59-preset.json there is now a u59-preset.<title id>.json for twelve title ids; the launcher applies it when you start that game. u59-preset.json itself is unchanged from int21.
  • Launcher: other games start with the launcher settings they were tested with (readback, tessellation and the like), unless you saved a config for that game yourself; for that case the game's configuration has a new Recommended button, and Reset returns to those settings too. The default window size is now 1920x1080 (a settings file from an earlier version keeps its saved size). Also a per-game option "Faster GPU synchronisation (experimental)", off by default (about 1 fps in heavy Astro Bot scenes; turn it off if graphics glitch), and a clear message instead of a crash on CPUs without AVX2.
  • Other games: additional games now boot. They are experimental.
  • Fixed (GPU device loss during a level load): a compute dispatch that writes through addresses it computes itself, into memory that had no GPU buffer yet, kept only its first 4,096 stores, and a later dispatch could then hang the GPU. It hit one of the other games in most boots of the fastest builds.
  • Upstream KytyPS5: 208 upstream changes (through bc934ef03), among them the PSSR pass and BVH8 intersections for Pro mode, skipped draws with an empty scissor, runs of indirect draws as one multi-draw, and many shader and texture fixes.
  • Fixed: add-on content counts as owned only when it is installed; u59-preset.json may contain comments and a trailing comma, and a syntax error names its line (#85); Astro Bot's videos decode on several threads and skip frames that are already late; shader validation uses the layout the device enables and is off by default (#77).
  • Thanks: the players on Discord who sent shader lists; TheCruZ, Senaxx, chenxiao07, usa-ratt, strxno and Erlou93 for the fork changes ported here; sniperspy69 (#67) and luizhtss (#68) for their pull requests; and the upstream KytyPS5 contributors.
  • Known issues: rare GPU device losses can still happen; please report them with _kyty.txt and _device_fault.nv-gpudmp. Precompile builds the listed shaders and the pipelines whose shaders are known before the game runs (about a quarter of the listed pipelines for Astro Bot); the rest are built on first use, as before. The Astro Bot shader list was made for 01.018 and is untested on 01.019; it does not fit 01.007 (title id PPSA21564), which gets the same preset but has no list yet. The Linux build of this version is untested.
  • Upgrading: extract into a new folder. The per-game preset files must sit next to the launcher together with u59-preset.json; an old folder without them runs without the new settings.
