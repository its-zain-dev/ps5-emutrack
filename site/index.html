    Contribute

    Everything goes through GitHub issues. You don't need an account anywhere else.

    1. Open a form

      Use the Submit emulator or Compatibility report form. Reports need a video, screenshot or log as evidence.

    2. Automatic checks

      A bot checks the repository right away: it exists, is public, isn't a duplicate, and has a license. It posts the results as a comment.

    3. Maintainer approval

      When a maintainer adds the approved label, the entry is committed to data/ and the site redeploys within minutes.

    FAQ

    Can a PS5 emulator run my games today?

    Some titles boot, and a few are playable on the most mature projects. Performance varies a lot between builds and GPUs. Check the compatibility table, and treat entries without evidence as unconfirmed.

    How do I avoid fake or malicious "PS5 emulators"?

    Real emulators are open source and published on GitHub. Be wary of anything that asks you to complete a survey, enter a password, or download from a file-sharing site. Community listings here are only lightly checked, so prefer featured projects and download only from the project's own GitHub Releases page.

    Where do I get games, firmware or keys?

    Not here. Emulators require you to dump games and system files from hardware you own. PS5 EmuTrack never links to copyrighted games, firmware, BIOS files or keys, and such requests will be closed.

    What do the compatibility statuses mean?

    Nothing: doesn't start. Boots: shows a logo or loading screen. Menus: reaches menus but not gameplay. In-Game: gameplay works with major issues. Playable: can be completed with acceptable performance.

    How is the data updated?

    A GitHub Action rebuilds data.json every hour from the GitHub API, using the curated lists in the repository's data/ folder. If GitHub is unreachable, the last good snapshot is kept.
